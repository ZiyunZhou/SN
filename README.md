# SN
Image-based construction and analysis of stromatolite spatial networks.

#### Main Steps
- Image preprocessing and stromatolite segmentation.
- Partitioning of the empty space using Delaunay triangulation.
- Construction of stromatolite spatial networks.
- Calculation and analysis of network properties.
- Visualization of network characteristics.
